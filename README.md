# Recipe Finder App

A modern web application to search and discover recipes from around the world using TheMealDB API.

## Features

- 🔍 Search recipes by name or ingredient
- 🏷️ Filter by category (Beef, Chicken, Vegetarian, etc.)
- ⭐ Save favorites with localStorage
- 📱 Responsive design
- 🎨 Smooth animations with Framer Motion

## Tech Stack

- **React.js** - UI framework
- **Axios** - HTTP client for API calls
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **Vite** - Build tool

## Getting Started

### Installation

```bash
cd my-app
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

## API

Uses [TheMealDB API](https://www.themealdb.com/api.php) for recipe data.
